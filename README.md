### 👥 Тестовые роли :
Переключение ролей осуществляется в левом боковом меню:
1. **👨‍🔧 Мастер смены (Касымов Д. М.):**
   - Оперативная канбан-доска текущей смены (530+ исторических нарядов в SQLite).
   - Быстрая выдача наряда менее чем за 1 минуту (< 6 кликов) либо мгновенный выбор по QR-шильдику агрегата (`INV-DR-001` [Конвейер К-3]).
   - AI-контроль дедлайнов и автоматическая эскалация аварийных нарядов, не принятых более 3 минут.
   - AI-Copilot смены: оперативные консультации на естественном языке по свободным специалистам и просрочкам.
2. **📱 Исполнитель (Ахметов Е. К. — Слесарь 5 разряда):**
   - Сенсорный мобильный интерфейс с крупными кнопками под рабочие перчатки.
   - Смена статусов: «Принять в работу», «Приостановить (ожидание ТМЦ)», «Отклонить с причиной».
   - Форма сдачи работ: списание нормативных ТМЦ и обязательная загрузка фотофиксации «После».
   - **Мультимодальный аудит ИИ:** при попытке сдать наряд без фото система выставляет 40/100 и отправляет «На доработку». При наличии фото — выносит вердикт «Принято» (95+/100).
3. **📊 Руководитель / ТОиР Аналитика (Главный механик):**
   - Экономический эффект: расчет упущенной выгоды (предотвращено 48.5 часов простоев = **21 800 000 ₸ экономии**).
   - **🧠 Предиктивный радар отказов (Machine Learning):** детекция скрытой аномалии — выявление 7 поломок Конвейера К-3 по шифру М-02 и предупреждение об аварии с вероятностью 87.4% на 7 смен вперед.
   - Официальный документооборот: выгрузка заверенного паспорта ТОиР в PDF и реестра смены в Excel (.xlsx).
4. **⚙️ Администратор НСИ:**
   - Ведение нормативно-справочной информации: единицы оборудования, штат сотрудников, складские остатки ТМЦ и шифры неисправностей (М, Э, Г, П, С).
   - Интеграционный шлюз 1С: генерация стандартизированных JSON-пакетов для ERP/1С:ТОиР.

## 🛠️ Архитектура и технологический стек
- **Frontend / Application Layer:** Python 3.10+, Streamlit (с кастомным индустриальным SCADA/Corporate темным интерфейсом).
- **Database:** SQLite3 / SQLAlchemy (8 реляционных таблиц по разделу 8 ТЗ, 529 сгенерированных нарядов с заложенной аномалией).
- **AI Core & Vision:** Мультимодальный анализ текстовых отчетов и фотофиксации, эвристический предиктивный алгоритм выявления скрытых цепочек отказов.
- **Интеграции и отчетность:** ReportLab (генерация PDF-актов), OpenPyXL (Excel-журналы), REST/JSON шлюз для 1С:ТОиР.
- **Отказоустойчивость:** Offline-first архитектура с поддержкой работы в условиях нестабильной связи в карьерах и шахтах Житигары.
- **Интернационализация:** Двуязычный интерфейс (Қазақша / Русский).

## 🚀 Инструкция по локальному запуску

# 1. Клонирование репозитория
git clone https://github.com/NO7Nd7oo/naryad-ai
cd naryad-ai

# 2. Создание и активация виртуального окружения
uv venv .venv
.venv\Scripts\activate   # Для Windows PowerShell
# source .venv/bin/activate # Для Linux / macOS

# 3. Установка зафиксированных зависимостей
uv pip install -r requirements.txt

# 4. Запуск системы
streamlit run app.py
